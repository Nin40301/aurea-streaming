Os arquivos HLS são transcodificações dos trailers completos (H.264/AAC). JPGs são quadros recortados dos mesmos trailers. O catálogo “Mundos da Blender” organiza os dois trailers como uma coleção demonstrativa; não representa uma série originalmente produzida por esses autores. `credits.vtt` é uma faixa de créditos criada pelo projeto, não tradução dos diálogos.
